Features

Everything you need to find your next target

BountyRadar runs quietly while you browse and gives you the answer when you click the icon.

Site radar

On any site – facebook.com, tesla.com, github.com – the icon lights up with a green ✓ if the company runs a program.

In-scope domains, one click

Wildcards and hosts from the platform's scope list, one per line – ready for subfinder -dL or httpx -l.

Auto-tracks program pages

Land on a policy page and it's saved with favicon, title and URL. Recognises Bugcrowd / HackerOne embeds, VDPs and "programme" spellings.

76 curated dorks

Cleaned-up Google dorks grouped by program URLs, page phrases, platforms, security.txt and country TLDs – one click each.

Search-result scanning

Optional: open a dork and BountyRadar checks the result pages in the background, adding every program it finds.

Export to ChatGPT

Send your tracked list to ChatGPT and get back normalized JSON: reward range, platform, in-scope and out-of-scope domains.

How it works

Four checks on every new domain

Results are cached per domain for a week, so revisits are instant. Hit Recheck any time.

Program directory

1,500+ public programs from ProjectDiscovery, HackerOne, Bugcrowd, Intigriti and YesWeHack – refreshed weekly, searched locally.

security.txt

Reads /.well-known/security.txt and follows its Policy: and Contact: links.

Security links

Follows footer links like "Security", "Bug Bounty" or "Responsible Disclosure" on the page you're on.

Common paths

Probes /security, /bug-bounty, /responsible-disclosure, /whitehat and friends.

Install

Up and running in a minute

BountyRadar loads as an unpacked extension in any recent Chrome (Manifest V3).

  1. Download the codeGrab the ZIP from GitHub and unzip it, or clone the repo.
  2. Open chrome://extensionsPaste it into the address bar.
  3. Enable Developer modeToggle in the top-right corner.
  4. Load unpackedSelect the folder that contains manifest.json.
  5. Pin itPuzzle-piece icon → pin BountyRadar, then visit any site.
# get the extension
git clone https://github.com/sudoninja-noob/BountyRadar

# visit tesla.com → click "Copy" under In scope
# then feed it straight into recon:
pbpaste | sed 's/^\*\.//' | subfinder -dL - -silent \
  | httpx -silent -title

✓ tesla.com runs a bug bounty program (Bugcrowd)
Privacy

Your browsing stays yours

Local by default

Detection and directory lookups run in your browser. Tracked programs live in chrome.storage.local.

First-party requests only

Site checks request security.txt and program paths from the site you're already on. No third-party favicon or analytics services.

You're in control

Site checks and search-result scanning each have a toggle. Data leaves only when you click Copy or ChatGPT.
